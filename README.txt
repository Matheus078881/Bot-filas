BOT DISCORD - PAINEL 1V1 / 2V2 / 3V3 / 4V4

O bot usa Python e discord.py.

IMPORTANTE:
- Nunca coloque o token do Discord dentro do código.
- No Render, crie a variável de ambiente DISCORD_TOKEN e cole o token nela.
- Se o token aparecer para outra pessoa, gere um novo token no Discord Developer Portal.

Depois que o bot estiver online, use /painel no seu servidor para enviar o painel.
